# Welcome to my Ride Hailing Expo app 👋

Welcome to my Ride Hailing Expo App! This is an [Expo](https://expo.dev) project created with [`create-expo-app`](https://www.npmjs.com/package/create-expo-app), showcasing a full-stack ride-hailing solution inspired by apps like Uber. Built with React Native, Node.js, and integrated with services like Clerk (authentication), Stripe (payments), Google Maps (geolocation), and Groq (AI chat), this app offers a seamless experience for urban commuters. Key features include real-time ride booking, secure payment processing, AI-powered chat support, and a user-friendly interface, all validated with 100% test coverage (22 tests across 10 suites) and optimized performance (55–60 FPS, 100–150 MB RAM).

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
    npx expo start
   ```
